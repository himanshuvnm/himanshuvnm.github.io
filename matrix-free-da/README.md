# Matrix-Free Covariance-Response — Research Website

Companion project page for **Matrix-Free Covariance-Response Approach for Data Assimilation-Ready Weather Ensembles** (NeurIPS 2026).

**Paper:** https://openreview.net/pdf?id=HQvUxeF3jA  
**Code:** https://github.com/himanshuvnm/matrix-free-da

## Publish on GitHub Pages

Copy `index.html` to the following directory inside the central repository:

`himanshuvnm.github.io/matrix-free-da/index.html`

After committing, the expected website URL is:

https://himanshuvnm.github.io/matrix-free-da/

This package does **not** replace the portfolio root `index.html`.

## Contents

- Motivation: scalar spread versus covariance response
- Ensemble covariance and Kalman-gain mathematics
- Matrix-free covariance-vector products
- Interactive, pedagogical two-dimensional covariance explorer
- Evaluation framework and direct links to the manuscript and code

## Scientific scope

The interactive example is illustrative and not a reproduction of the paper's reported experiments. The source repository was not accessible during website creation, so no numerical experimental outcomes, datasets, or code-specific reproduction instructions have been invented. Integrate exact figures and benchmark results after repository access is available.
