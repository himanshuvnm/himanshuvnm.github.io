## ✨ Featured research websites

### Operator-Adapted Reproducing Kernel Geometries

An interactive presentation of the inverse geometry problem: for a given operator, construct an RKHS inner product in which it acts isometrically. Includes existence and classification results, numerical evidence, and a mathematical laboratory.

[🌐 Website](https://himanshuvnm.github.io/operator-adapted-rkhs/) · [📄 Paper](https://openreview.net/pdf?id=wBN8kwEGN8) · [💻 Research code](https://github.com/himanshuvnm/operator-adapted-rkhs-)

### Kernelized Koopman Representation Geometry

Explores the relationship between kernel-induced representation geometry, non-normality, and transient amplification in neural dynamical systems. Includes interactive visualizations and a learning studio.

[🌐 Website](https://himanshuvnm.github.io/kernelized-koopman-representation-geometry/) · [📄 Paper](https://openreview.net/pdf?id=ZKhFhmuyuq) · [💻 Research code](https://github.com/himanshuvnm/KEDMD_TA_SPIKES)

### Koopman–Laplacian KEDMD

Research website for kernel dynamic mode decomposition, Laplacian RKHS structure, and sparse reconstruction of dynamical systems.

[🌐 Website](https://himanshuvnm.github.io/koopman-lap-kedmd/) · [📄 Paper](https://arxiv.org/abs/2505.06806)

## 🧭 Finding a website quickly

1. Search this README using **Ctrl+F** (or **⌘+F** on macOS) for the project name.
2. Open **Visit website** for the published page, or the source-folder link to edit it.
3. When adding a project, add one row to the directory table and optionally a featured description.

## ➕ Add a new project

Copy this table row and replace the placeholders:

```markdown
| **Project name** | Research area | [Visit website](https://himanshuvnm.github.io/PROJECT-SLUG/) | [`PROJECT-SLUG/`](./PROJECT-SLUG/) |
```

Only add the live website link after confirming that the deployed URL works. A GitHub Pages project slug generally follows the subdirectory name, but this should be checked rather than assumed.
