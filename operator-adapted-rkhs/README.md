# Operator-Adapted RKHS Geometries — Project Website

Standalone GitHub Pages project microsite for the accepted NeurIPS 2026 GlobalSouthAI paper.

## Deployment

Upload the **contents of this directory** into a new folder named `operator-adapted-rkhs` in the existing `himanshuvnm/himanshuvnm.github.io` repository. Do not replace the repository's root `index.html`.

Published URL: https://himanshuvnm.github.io/operator-adapted-rkhs/

## Files
- `index.html` — self-contained website and interactive mathematical illustration (MathJax loaded from CDN)
- `assets/operator-adapted-rkhs-paper.pdf` — accepted manuscript supplied by user
- `assets/paper-figure.jpg` — Figure 1 extracted from the accepted manuscript

## Notes
- All theoretical claims and numerical measurements are sourced from the accepted manuscript.
- The 2D shear-and-rotation demo is an analytically exact pedagogical illustration, not a reproduction of the paper's 20D numerical experiment.
- No numerical results from the GitHub repository were independently inspected because the repository could not be retrieved during site generation. The site links to the repository without claiming repository-specific details.
- Test in a browser and confirm the project repository URL before publication.
